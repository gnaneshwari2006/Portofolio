# Kada Gnaneshwaridevi Portfolio

Responsive one-page portfolio built with HTML, CSS and JavaScript.

## Files
- index.html
- styles.css
- script.js
- resume.pdf

## Run
Open `index.html` directly, or use VS Code Live Server.

## Deploy with GitHub Pages
1. Create a GitHub repository, e.g. `portfolio`.
2. Upload these files.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/root`.
5. Save and open the generated GitHub Pages URL.

The portfolio intentionally does not publicly display the phone number. Email, GitHub and LinkedIn are provided instead.
